# Video Sampler — Four Pad Prototype

[GitHub Pages에서 실행하기](https://jkandrea.github.io/video-sampler/)

로컬 영상을 재생하면서 네 패드에 서로 다른 구간을 수집하고, 메트로놈에 맞춰 독립적으로 연주하는 React + TypeScript 프로토타입이다.

## 실행

```bash
npm install
npm run dev
```

프로덕션 빌드는 다음 명령으로 확인한다.

```bash
npm run build
```

## 사용 방법

1. `영상 불러오기`에서 첫 번째 로컬 영상 파일을 선택한다.
2. `영상 추가`로 다른 영상을 더 등록하고, 소스 선택 메뉴에서 샘플링할 영상을 고른다.
3. 소스 영상을 재생한다.
4. 원하는 장면이 나오는 동안 `PAD 01`부터 `PAD 04` 중 하나를 누르고 있는다.
5. 패드를 떼면 해당 구간과 소스 영상 참조가 함께 저장된다.
6. `연주` 모드로 전환하고 패드를 누르면 저장한 구간이 재생된다.
7. 재생 중 패드를 다시 누르면 현재 위치를 멈추고 샘플의 IN 지점부터 다시 재생한다.
8. 패드는 마우스·터치 또는 키보드 `A`, `S`, `D`, `F` 키로 조작할 수 있다.
9. 메트로놈의 BPM을 설정하고 `METRONOME` 버튼으로 시작하거나 정지한다.
10. 연주 모드에서 패드별 `LOOP`를 켜면 해당 샘플의 IN~OUT 길이로 독립 반복한다.

같은 패드에 다시 샘플링하면 기존 구간을 덮어쓴다. `마지막 덮어쓰기 취소`로 직전 샘플을 한 번 복원할 수 있다.

영상 파일은 서버에 업로드하지 않으며 브라우저의 로컬 Object URL로만 사용한다. 새로고침하면 현재 샘플은 초기화된다.

## 현재 범위

- 여러 로컬 소스 영상 등록 및 전환
- 패드별 소스 영상 ID 유지
- 독립적인 샘플 패드 4개
- 네 패드 동시 영상·오디오 재생
- 누르고 있는 동안 IN/OUT 구간 수집
- One-shot + Retrigger 구간 재생
- 패드별 독립 샘플 길이 루프
- 40~240 BPM Web Audio 메트로놈
- 마지막 덮어쓰기 실행 취소
- `play()` 응답, 첫 영상 프레임 및 AudioContext 레이턴시 진단

프로덕션 제품 기획은 [doc/video-sampler-product-plan.md](doc/video-sampler-product-plan.md)를 참고한다.

현재 루프는 각 샘플의 실제 길이를 그대로 반복한다. BPM 마디에 맞춘 길이 보정, 다음 마디부터 시작, Overdub 이벤트 녹음은 다음 루프 스테이션 단계의 범위다.
